# Examples

- `tobacco_panel.csv`: deterministic balanced panel generated by
  `scripts/make_example_panel.py --first-treated-period 1989`. One treated unit
  (`treated`) plus 15 donors over 1980-2000 (`unit_id,period,treatment_group,Z1,Z2,Y_observed`).
  The treated unit's pre-treatment series is a fixed convex combination of four
  donors, and a true additive effect of `-8` is applied from 1989 onward, so a
  correct estimator recovers an ATT near `-8`.
- Regenerate with:
  `python3 scripts/make_example_panel.py --out examples/tobacco_panel.csv --first-treated-period 1989`

This is a meaningful fixture, not a smoke placeholder: it exercises the full
Synth fit, donor weighting, counterfactual projection, and ATT computation.
