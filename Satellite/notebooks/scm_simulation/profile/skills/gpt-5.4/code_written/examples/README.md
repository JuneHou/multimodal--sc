# Example Data

`toy_tobacco_panel.csv` is a deterministic balanced panel with one treated unit and four donors across eight yearly periods.

- Treated unit: `treated`
- Pre-treatment periods: `2001` to `2005`
- Treated periods used in the smoke path: `2006`, `2007`, `2008`
- Outcome: `Y_observed`
- Predictors: `Z1`, `Z2`

The post-treatment treated outcome is below the donor-based synthetic control, so the expected ATT is negative.
