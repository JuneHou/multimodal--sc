An answer’s ATT̂ is the mean over periods 41 to 60 of the treated unit’s outcome minus the answer’s counterfactual, as the collaborator’s code computes it. The README column averages each row over the collaborator’s 1,000 replications, the last two over 100. An answer’s leave‑one‑out refits use its own specification and search V again where the answer did, while the collaborator’s code fixes V at the identity.
Rows of the results tables, the formula for one answer, and the README section and evaluation code lines that define each.
NOTES: The first code line computes the measure for one replication and the second averages it over replications. For a configure or design answer the measures use the fit that produced it, and for a profile answer the skill script’s specification refitted with Synth, which reproduces every answer within 0.0001 in every period. An answer whose counterfactual no recorded fit gives has no fit behind it, and its rows that need a fit read no fit.
