Skill formats

The formats differ in who writes the method

formatcode the model runswhat the model decideswhat the code fixes
scm‑configurea fitter that runs Synth 1.1-10 unchanged13 Synth settings, the predictors and their periods, the donor pool, V or its search, the optimizers and the solver’s precisionconvex weights, no penalty
scm‑designthe same fitter with the paper’s two alternatives addedthe 13 settings, convex or extrapolation weights, and a distance penalty with its sizeSynth’s own code
profile, GPT‑5.4 generatoran R script that GPT‑5.4 wrote through SkillFoundry from the paper and Synth’s sourcehow to call the scriptZ1 and Z2 means and the outcome at each pre-treatment period, V searched
profile, DeepSeek generatoran R script that DeepSeek‑V4.1‑Flash wrote the same wayhow to call the script, with options for predictors, outcome lags, V and optimizersby default Z1 and Z2 means, V searched

Under scm‑configure and scm‑design the model writes the specification itself and runs the fitter at it. Under a profile skill the generator’s script holds the specification, and the model calls the script.

Contents of each skill as the solver models received it.

scm‑configure and scm‑design each hold a method reference, a settings reference, a data viewer and the fitter. Each SkillFoundry generator received the same request, the paper and Synth’s CRAN source.
