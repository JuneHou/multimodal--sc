Step 1 — Standard SCM: Simplex-Constrained Least Squares

OBJECTIVE
$$\mathbf{w}^{\rm SCM}=\underset{w_j\geq0,\,\sum w_j=1}{\arg\min}\,\|\mathbf{y}_1-\mathbf{Y}_0\mathbf{w}\|^2$$

Inputs: y₁∈ℝ56, Y₀∈ℝ56×5

QP FORM
$$D=\mathbf{Y}_0^\top\mathbf{Y}_0+\varepsilon I_J$$ $$\mathbf{d}=\mathbf{Y}_0^\top\mathbf{y}_1$$ $$\min_w\tfrac{1}{2}\mathbf{w}^\top D\mathbf{w}-\mathbf{d}^\top\mathbf{w}$$ $$\text{s.t. }\mathbf{1}^\top\mathbf{w}=1,\;\mathbf{w}\geq\mathbf{0}$$
PYTHON (SLSQP)
D = Y0.T @ Y0 + 1e-7*eye(J)
d = Y0.T @ y1

minimize(obj, w0,
  method='SLSQP',
  bounds=[(0,1)]*J,
  constraints=[sum(w)==1]
)
D = Y₀ᵀY₀ (5×5)
$$D_{ij}=\sum_{t,k} Y_{0,tki}\cdot Y_{0,tkj}$$

Step 2 — Augmented SCM: Ridge Penalty Anchored to wSCM

ASCM OBJECTIVE
$$\mathbf{w}^{\rm ASCM}=\underset{\sum w_j=1}{\arg\min}\,\|\mathbf{y}_1-\mathbf{Y}_0\mathbf{w}\|^2+\lambda\|\mathbf{w}-\mathbf{w}^{\rm SCM}\|^2$$

Drop w≥0 • Add ridge to anchor near wSCM

MODIFIED QP MATRICES
$$D^{\rm ASCM}=D^{\rm SCM}+\lambda I_J$$ $$\mathbf{d}^{\rm ASCM}=\mathbf{d}^{\rm SCM}+\lambda\,\mathbf{w}^{\rm SCM}$$

Large λ inflates diagonal of D • pulls solution toward wSCM

$$D^{\rm ASCM}_{\rm diag}=[10005, 10009, 10020, 10002, 10005]$$

λ=10,000 added to each diagonal entry

KKT CLOSED-FORM
H = eye(J)+(Y0.T@Y0)/lam
b = w_scm+(Y0.T@y1)/lam
KKT=block([[H,ones],
           [ones.T,[[0]]]])
rhs=r_[b,[1.0]]
w = solve(KKT,rhs)[:J]

λ via leave-one-period-out CV • treatment_0001: λ*=10,000

Why Multiple Outcomes? Formal Bias Reduction O(1/√KT₀)

STANDARD SCM — 1 OUTCOME
$$\text{Bias}=O\!\left(\frac{1}{\sqrt{T_0}}\right)$$

T₀=7 periods, K=1 → effective mass = 7

MULTI-OUTCOME SCM — K OUTCOMES
$$\text{Bias}=O\!\left(\frac{1}{\sqrt{K\cdot T_0}}\right)$$

K=8, T₀=7 → effective mass = 56  (8× more)

KEY CONDITION

All K outcomes must share a common latent factor μₜ:

$$Y_{{ikt}}=\mu_t^\top\lambda_{{ik}}+\delta_{{ikt}}+\varepsilon_{{ikt}}$$

Sentinel-2 bands all driven by vegetation, moisture & soil structure → valid grouping

fn_W SOLVER (used for both Germany & COVID)
fn_W = function(Zi, ZJ, V) {
  J = nrow(ZJ)
  D = ZJ %*% V %*% t(ZJ) + 1e-7*diag(J)
  d = ZJ %*% V %*% Zi
  A = cbind(rep(1,J), diag(J))
  solve.QP(D, d, A, c(1,rep(0,J)), meq=1)$solution
}

SCM vs ASCM Validation — P10 Hold-Out RMSE by Band & Site

SCM vs ASCM COMPARISON

Both methods use the same 56-row design matrix (8 bands × 7 periods).

SCM (λ=∞ limit): simplex-constrained, no negative weights
ASCM (ridge, λ tuned by CV): allows negative weights, anchored to SCM solution

VALIDATION INTERPRETATION

• Points above diagonal: SCM worse than ASCM
• Points below diagonal: ASCM worse than SCM
• Clustering near diagonal: methods are similar

Large λ (10,000) keeps ASCM close to SCM → nearly identical validation performance across bands and sites

OVERALL FINDING

SCM-MO Exp2 (P01–P09 × 8 bands) achieves lowest RMSE overall.

Ridge ASCM correction minimal at λ=10,000 — SCM provides strong baseline when donor pool is small (J=5) and pre-treatment fit is already excellent.
